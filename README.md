# Mahin POS - Cloud Multi-Tenant POS & Shop Management System

আধুনিক, বিদ্যুৎগতির ক্লাউড পয়েন্ট অব সেল (POS), ইনভেন্টরি ও দোকান ম্যানেজমেন্ট সিস্টেম। এটি **Firebase + Cloudflare Pages + Cloudflare Workers + Cloudinary** দিয়ে তৈরি একটি সম্পূর্ণ মাল্টিটেন্যান্ট প্ল্যাটফর্ম।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

### ১. হাইপার-ফাস্ট POS বিলিং টার্মিনাল (`/dashboard/pos`)
- **১০০০+ পণ্যের তাৎক্ষণিক সার্চ:** নাম, বারকোড, বা এসকেইউ (SKU) দিয়ে মুহূর্তের মধ্যে অনুসন্ধান।
- **হার্ডওয়্যার বারকোড স্ক্যানার সাপোর্ট:** USB / ব্লুটুথ স্ক্যানার দিয়ে স্ক্যান করলেই স্বয়ংক্রিয়ভাবে অডিও বিফ সহ কার্টে যোগ।
- **কীবোর্ড শর্টকাট:**
  - `F2`: পণ্য সার্চ ফিল্ড ফোকাস
  - `F4`: সরাসরি বিল পরিশোধ ও চেকআউট
  - `Esc`: পেমেন্ট মোডাল বা উইন্ডো ক্লোজ
- **হোল্ড কার্ট (Hold Cart):** একজন কাস্টমার সিদ্ধান্ত নেওয়ার সময় অন্য কাস্টমারকে সেবা দিতে কার্ট হোল্ড এবং পরবর্তীতে ১-ক্লিকে রিজিউম।
- **বিবিধ পেমেন্ট মেথড:** ক্যাশ (নগদ), বিকাশ, নগদ, কার্ড ও বাকি (Due)।
- **স্বয়ংক্রিয় ফেরত টাকা (Change Return):** প্রাপ্ত টাকা লিখলেই তাৎক্ষণিক ফেরতযোগ্য টাকা হিসাব।

### ২. ৩টি বিশেষ ইনভয়েস ফরম্যাট (Multi-Format Invoices)
১. **থার্মাল POS রোল (58mm / 80mm):** সুপারশপ ও মুদি দোকানের জন্য কম্প্যাক্ট রিসিপ্ট।  
২. **ঐতিহ্যবাহী ক্যাশ মেমো (A5 Half-Sheet):** বাংলা দোকান সিল ও স্বাক্ষর এরিয়া সহ ঐতিহ্যবাহী ক্যাশ মেমো।  
৩. **অফিসিয়াল ইনভয়েস (A4 Corporate):** পূর্ণাঙ্গ চালান ও ভ্যাট/ট্যাক্স বিল।

### ৩. কাস্টমার লয়্যালটি রিওয়ার্ড পয়েন্টস (Rewards Points)
- প্রতি ১০০ টাকার কেনাকাটায় ১ পয়েন্ট অর্জন।
- পরবর্তী কেনাকাটায় কাস্টমার পয়েন্ট রিডিম করে সরাসরি ক্যাশ ডিসকাউন্ট পেতে পারেন।

### ৪. ইনভেন্টরি, বারকোড ও কম স্টক সতর্কতা
- পণ্যের ক্রয় মূল্য (Cost), বিক্রয় মূল্য (MRP), পাইকারি মূল্য ও বর্তমান স্টক ট্র্যাকিং।
- **বারকোড স্টিকার প্রিন্ট সেন্টার:** দোকানে লাগানো যায় এমন ১২/২৪/৪০ টি স্টিকার সমৃদ্ধ শিট প্রিন্ট।
- **কম স্টক সতর্কতা (Low Stock Alerts):** স্টক নির্দিষ্ট সীমার নিচে নামলেই রিয়েল-টাইম এলার্ট ও রি-অর্ডার তালিকা।

### ৫. হিসাব, লাভ-ক্ষতি ও ক্যাশ খাতা
- **প্রকৃত লাভ-ক্ষতি (Profit & Loss):** পণ্যের ক্রয় খরচ (COGS) বনাম বিক্রয় মূল্য থেকে গ্রস প্রফিট এবং দোকান খরচ বাদ দিয়ে নেট প্রফিট।
- **খরচের খাতা (Expense Manager):** দোকান ভাড়া, বিদ্যুৎ বিল, কর্মচারীর বেতন, আপ্যায়ন ইত্যাদি।
- **গ্রাহক বাকি খাতা (Customer Ledger):** বাকি পাওনা ট্র্যাকিং ও বাকি আদায়।
- **দৈনিক ক্যাশ খাতা (Daily Cash Register):** প্রারম্ভিক ক্যাশ, ক্যাশ ইন ও ক্যাশ আউট ট্র্যাকিং।

### ৬. সুপার এডমিন কন্ট্রোল সেন্টার (`/mahinerp`)
- সকল দোকান টেন্যান্ট তালিকা ও প্যাকেজ নিয়ন্ত্রণ (Starter, Pro, Enterprise)।
- **⚡ ১-ক্লিক ইম্পারসনেশন (Login as Owner):** পাসওয়ার্ড ছাড়াই যেকোনো দোকানে প্রবেশ করে সমস্যা সমাধান।
- **হাইব্রিড ক্লাউড ও ডেটাবেস:** শেয়ার্ড ফায়ারবেস অথবা ডেডিকেটেড ফায়ারবেস নির্বাচন।
- **সার্বজনীন ব্রডকাস্ট নোটিশ:** সকল দোকানের ড্যাশবোর্ডে নোটিশ প্রচার।

## 🛠️ প্রযুক্তি ও আর্কিটেকচার (Tech Stack)

- **Frontend:** React 19 + Vite 6 + React Router 7 + React Hot Toast
- **Database & Auth:** Firebase Firestore & Firebase Authentication (`mahinpos`)
- **API & Gateway:** Cloudflare Worker (`cloudflare-worker/worker.js`)
- **Image Optimization:** Cloudinary CDN + Browser Canvas Compression
- **Hosting:** Cloudflare Pages / Firebase Hosting

## 🚀 ক্লাউডফ্লেয়ার ও ডেপ্লয়মেন্ট গাইড

### Cloudflare Pages এ হোস্ট করার নিয়ম:
1. Github রিপোজিটরিটি Cloudflare Pages এ যুক্ত করুন।
2. **Build Settings:**
   - Framework preset: `Vite`
   - Build command: `npm run build`
   - Build output directory: `dist`
3. SPA রাউটিংয়ের জন্য `_redirects` ফাইলটি ইতিমধ্যে অন্তর্ভুক্ত আছে।

### Cloudflare Workers (SMS & Payment Gateway) ডেপ্লয়:
```bash
cd cloudflare-worker
npx wrangler deploy
```
